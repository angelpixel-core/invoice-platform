# Invoice Platform

Multi-tenant invoice integration SaaS proof of concept built with Vue, TypeScript and NestJS, focused on resilient APIs, third-party integrations, event-driven workflows and AWS.

## Stack

- Frontend: Vue 3 + TypeScript + Vite
- Backend: NestJS + TypeScript
- Package manager: pnpm
- Strict TypeScript configuration

Vue and NestJS are independent TypeScript applications. They communicate through HTTP APIs and do not need to share a runtime or framework.
